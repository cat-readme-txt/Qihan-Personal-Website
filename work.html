Research

Methods, validation, and systems work

Oct. 2026–present · Dr. Soham Pal · UIUC

Nuclear pasta simulation

Implemented an FP64 CUDA all-pairs force kernel for dense nuclear matter, with periodic boundaries, screened Coulomb interactions, and shifted-force cutoffs. Built a velocity-Verlet CPU reference with reproducible checkpoints and CPU/GPU agreement checks.

In documented CPU tests, 60 force gradients passed finite-difference checks, relative momentum drift stayed below 10−14, and reversal error stayed below 10−9 fm.

Nov. 2026–present · Professor Sever Tipei · UIUC

DISSCO / LASS CUDA filtering

Implemented an optional CUDA backend for sound-level biquad filters, using 256-sample chunks and parallel state propagation for recursive IIR processing. Added GPU selection, asynchronous transfers, and automatic CPU fallback.

Checked 65,539-sample signals against the CPU recurrence and public multichannel API. Matched Release benchmarks on NCSA Delta showed execution-time gains for tested workloads; complete-render acceleration remains a separate target.

DISSCO source

2026 · Independent research

Resource-constrained EEG classification

Built separate motor execution and imagery benchmarks using acquisition records for 109 participants per task. Compared band power, Hjorth parameters, wavelet energy, CSP, and filter-bank CSP with shrinkage LDA.

Evaluated subject transfer, calibration, shorter windows, fewer channels, and 16 noise or artifact scenarios. Kept compute latency separate from total decision delay.

EEG repository

Summer 2025 · Dr. Weidong Shi · University of Houston

LLM reasoning evaluation

Developed a repeated-trial benchmark across biology, mathematics, and law. Implemented response normalization, scoring, retry handling, and agreement measures including ICC and Krippendorff’s alpha.
