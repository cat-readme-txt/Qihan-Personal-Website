Oct. 2026–present · Dr. Soham Pal · UIUC

Nuclear pasta simulation

Dense nuclear matter needs a force model that behaves consistently at periodic boundaries and cutoffs. I built an FP64 CUDA all-pairs kernel with two-Gaussian nuclear interactions, screened Coulomb forces, and shifted-force cutoffs.

The C++20 CPU reference uses seeded initial conditions, NVE velocity Verlet, energy and momentum logs, and lossless checkpoints. It provides the numerical baseline for GPU agreement work.

Nov. 2026–present · Professor Sever Tipei · UIUC

DISSCO / LASS CUDA filtering

Recursive IIR filters carry state between samples, so I split sound-level biquad filtering into 256-sample chunks. Affine state summaries propagate each chunk’s boundary state before parallel evaluation on the GPU.

The optional CUDA build adds GPU selection, asynchronous transfers, RAII resource handling, and automatic CPU fallback. The correctness test checks the GPU filter against the CPU recurrence, including independent channels.

The same comparison’s synthetic LASS render used eight seconds of four-channel audio, eight partials, and disabled loudness and reverb. It took 306.63 ms with CPU filtering and 307.55 ms with CUDA filtering.

2026 · Independent research

Resource-constrained EEG classification

Can lightweight classifiers distinguish real and imagined left/right fist movement for people absent from training? I compared spectral, temporal, wavelet, CSP, and filter-bank CSP features with shrinkage LDA.

Separate execution and imagery benchmarks used acquisition records for 109 subjects per task. The historical local study tested subject transfer, calibration, channel reduction, shorter windows, and 16 artifact or noise scenarios. Follow-up validation is documented separately in the repository.

Summer 2025 / University of Houston

LLM cross-domain knowledge transfer

With Professor Weidong Shi, I built a Python benchmark that evaluates LLM accuracy across biology, mathematics, and law. The notebook normalizes and scores responses and uses intraclass correlation and Krippendorff’s alpha to compare repeated model runs.

Sept. 2026–present · Illini Solar Car

HIL sensors & PCB development

I designed a KiCad schematic to emulate brake outputs and main-current sensor voltage for hardware-in-the-loop tests. It specifies a dual 12-bit DAC with a 2.5 V reference and nominal 0–5 V output, plus independently enabled 3.3 V brake channels.

I also reviewed blind-spot sensor footprint and BOM dependencies, evaluated weather-resistant obstacle sensors, and configured a Zephyr environment for integration. Electrical choices and physical validation remain in progress.
