Quantum error correction · HackMidwest 2nd place · Infleqtion Challenge 1

ML-assisted quantum decoder.

Fast candidates for routine shots, deeper search when they disagree.

Our Gross-code decoder runs two independently seeded PriorTilt searches and compares their predicted logical flips. On disagreement, it adds a Relay-BP candidate and uses a trained neural network to rank the options.

Decoder source Evaluation report

12 logical qubits

The Gross code encodes 12 logical qubits in 144 data qubits at code distance 12.

8,784 fault effects

The circuit model maps candidate fault combinations to detector and logical flips.

3 noise settings

The evaluation used separate training, validation, and test shots at p = 0.003, 0.004, and 0.005.

Test scope

A pair fails if either memory shot has an incorrect logical prediction. Pair time sums the two software decodes.

Measure the same memory repeatedly and decode the history.

Digital hardware · SystemVerilogUrbana Spartan-7 prototype · 2026

FPGA decoder router.

Keep the first correction or ask the host to search again.

The Urbana design replays saved syndrome bits and statistics from an initial software decode. A four-stage fixed-point core scores the first candidate and returns a decision over UART. It implements the team’s first-solution routing policy.

FPGA source Board and simulation guide

5,000 saved shots

The validation vectors cover the frozen X-memory model and include the original simulated syndromes.

0 verdict mismatches

The fixed-point rule matched the floating-point reference on the saved validation set.

17 DSP slices

Yosys mapped the UART and router design to 983 LUTs, 688 flip-flops, and 17 DSP48E1 slices.

Validation

Saved-shot replay and RTL checks cover the routing decision. Physical board replay and measured timing remain open.
