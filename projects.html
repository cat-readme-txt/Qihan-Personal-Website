Strategy simulation · 2026

Chronodox.

Three timelines.
Every decision echoes.

A browser-based strategy game about agents competing across the past, present, and future. I built a custom TypeScript engine for hidden information, timeline traversal, an intel economy, and paradoxes that can destroy cities and agents.

Inspired by the iOS game Two Spies, then expanded with paradox mechanics and layered timelines.

Play Chronodox Source code
01

One shared engine

Procedural maps, cross-timeline movement, and paradox resolution power both playable matches and AI self-play.

02

Learning through self-play

A hybrid agent blends tactical heuristics with learned linear scores trained from more than 200,000 completed self-play samples. The browser uses checked-in policy artifacts.

03

From rules to interaction

Animated timelines and a command terminal. A snapshot serializer and optional Node.js room host synchronize clients through HTTP polling and revision-checked state updates.

Built with

TypeScript / React / Zustand / Vite / Node.js / Tailwind CSS / Framer Motion

Digital hardware · SystemVerilog · 2026

Pipelined INT8 FPGA accelerator

Built an eight-lane signed INT8 dot-product engine with exact 19-bit accumulation and ready/valid backpressure. Its four-stage pipeline accepts one vector per clock cycle without stalls.
