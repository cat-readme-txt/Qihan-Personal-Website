VoidNavigator.

Survive the field.
Cross into the Void.

A desktop arcade game about surviving timed asteroid waves and deciding when to enter a more dangerous world. Every fight can earn fuel or Incident Essence; every construction changes what your ship can do next.

The game loop

One ship. Two kinds of danger.

01 / The field

Keep moving.

Survive timed levels, break apart asteroids, and collect M-AM fuel to keep the ship moving. Cosmic entities and black holes change the shape of the field as a run advances.

02 / The Void

Change the threat.

Cross into the Void to pass through asteroids, but face Void creatures instead. Void energy rises while you stay there, making every visit a timed choice.

03 / Construction

Shape the ship.

Defeated threats grant Incident Essence. Spend it on weapon nozzles, active abilities, and passive systems such as Shield and Swarm.

Desktop project

A desktop game from start to finish.

VoidNavigator runs as a Java desktop application with rebindable keyboard controls and saved runs. The repository documents macOS, Windows, and portable Java build paths.
